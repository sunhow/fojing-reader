# Sunhow · 佛经精读

[在线阅读](https://sunhow.github.io/fojing-reader/)

统一的个人佛经阅读书架，保留原有五经顺序并追加三项：

1. 《佛遗教经》：22 段，4 个阅读小节。
2. 《佛说十善业道经》：19 段，5 个阅读小节。
3. 玄奘译《般若波罗蜜多心经》：7 段，1 个阅读小节。
4. 鸠摩罗什流通本《金刚般若波罗蜜经》：32 分，8 个阅读小节。
5. 般若译《普贤行愿品》单行部分：76 段，9 个阅读小节，含 62 组四句偈。

6. 《八大人觉经》：10 段完整正文，2 节。
7. 汉译《法句经》选读：20 首完整偈颂，5 个专题；每首注明所属品和起句，不是全经。
8. 罗什译《阿弥陀经》：20 段完整正文，4 节，不混入后附往生咒。

共 38 节、206 个原文／完整白话／阅读提示对照段落。书架另有原有 [地藏经](https://sunhow.github.io/dizang-reader/) 和 [易经](https://sunhow.github.io/yijing-reader/) 入口。

## 使用

- 按书架顺序选经，再选小节，逐段精读或通篇对照。
- 「看白话」只在当前位置展开，手机、电脑都不自动滚动。
- 阅读提示单独折叠；名词可点选查看，名词页按经书筛选。
- 支持简体／底本字形、全文检索、浏览器朗读、纸色与字号设置。
- 本地笔记、阅读位置、完成标记和 JSON 备份。新书架使用 `fojing.` 键名；已有网站数据各自保留，不自动迁移或合并。

白话、提示和词条为 AI 辅助学习稿，未经过佛教学者或法师逐条审定。版本范围与特殊字句见 [SOURCES.md](SOURCES.md)。

## 佛教基础名词导读

新增 `#/basics`，含三宝、四圣谛、八正道、戒定慧、业与十善、五蕴、缘起、无我、空性、菩提心、回向、净土信愿行，共 12 个主题。每篇包含通俗解释、常见误解、生活例子、相关概念和直达原文段落的链接。

主题支持筛选和全站搜索；名词卡片与浮层中有对应的深入导读入口。`#/passage/段落ID` 会定位到该原文段落。`foundations-source.json` 是可编辑导读，`foundations.js` 为构建产物，构建时检查所有主题和经文引用都可解析。

## 本地构建

Python 3.9+，构建无需第三方库。

```sh
python3 build_site.py
python3 -m http.server 4175 --bind 127.0.0.1 --directory dist
```

- `library-source.json`：八项经书与选读、译文、提示、阅读分组及版本信息。
- `source-manifest.json`：独立记录原文段数、顺序和 SHA-256，防止整理时漏段或混入其他文字。
- `glossary.json`：与正文关联的名词及深入导读链接。
- `config.js`：网站署名与名称。
- `build.py`：校验八项顺序、206 段覆盖、原文哈希、62 组愿王偈及重要首尾，再生成 `book.js`。
- `build_site.py`：生成 `dist/`，按资源内容更新离线缓存版本。

修改后构建，并将更新的源文件、`book.js` 与 `sw.js` 一并提交。不要仅为绕过原文检查修改清单哈希；文字订正应先核对来源并记录理由。

## 发布

GitHub Pages → Deploy from a branch → `main` → `/(root)`。仓库根目录即含可发布资源，无需提交 `dist/` 或设置自定义工作流。所有资源使用相对路径。首次更新可能经过离线缓存切换，再刷新一次可载入新版本。
