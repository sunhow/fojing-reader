# 佛经精读 · 原文白话对照

[在线阅读](https://sunhow.github.io/fojing-reader/)

面向所有读者的佛经阅读书架，将《地藏菩萨本愿经》并入《普贤行愿品》之后，依次收录：

1. 《佛遗教经》：22 段，4 个阅读小节。
2. 《佛说十善业道经》：19 段，5 个阅读小节。
3. 玄奘译《般若波罗蜜多心经》：7 段，1 个阅读小节。
4. 鸠摩罗什流通本《金刚般若波罗蜜经》：32 分，8 个阅读小节。
5. 般若译《普贤行愿品》单行部分：76 段，9 个阅读小节，含 62 组四句偈。
6. 《地藏菩萨本愿经》：三卷十三品，153 段完整原文、白话与阅读提示。
7. 《八大人觉经》：10 段完整正文，2 节。
8. 汉译《法句经》选读：20 首完整偈颂，5 个专题；每首注明所属品和起句，不是全经。
9. 罗什译《阿弥陀经》：20 段完整正文，4 节，不混入后附往生咒。

原白话书架共51节、359个原文／完整白话／阅读提示对照段落。另有四部原典与祖师注疏，188个卷／品阅读单元，7701个原文段落；全站合计13项、239个阅读单元。《地藏经》已在本站完整阅读；书架另有 [国学精读](https://sunhow.github.io/guoxue-reader/) 和 [易经](https://sunhow.github.io/yijing-reader/) 入口。

## 使用

- 按书架顺序选经，再选小节，逐段精读或通篇对照。
- 「看白话」只在当前位置展开，手机、电脑都不自动滚动。
- 阅读提示单独折叠；名词可点选查看，名词页按经书筛选。
- 支持简体／底本字形、全文检索、浏览器朗读、纸色与字号设置。
- 本地笔记、阅读位置、完成标记和 JSON 备份。新书架使用 `fojing.` 键名；同浏览器首次合并旧地藏站的笔记与进度，保留较新的记录；不删除旧站数据，不双向同步。也支持旧地藏站 JSON 备份导入。

白话、提示和词条为 AI 辅助学习稿，未经过佛教学者或法师逐条审定。版本范围与特殊字句见 [SOURCES.md](SOURCES.md)。

## 佛教基础名词导读

新增 `#/basics`，含三宝、四圣谛、八正道、戒定慧、业与十善、五蕴、缘起、无我、空性、菩提心、回向、净土信愿行，共 12 个主题。每篇包含通俗解释、常见误解、生活例子、相关概念和直达原文段落的链接。

主题支持筛选和全站搜索；名词卡片与浮层中有对应的深入导读入口。`#/passage/段落ID` 会定位到该原文段落。`foundations-source.json` 是可编辑导读，`foundations.js` 为构建产物，构建时检查所有主题和经文引用都可解析。

## 本地构建

Python 3.9+，构建无需第三方库。

```sh
python3 build_site.py
python3 -m http.server 4175 --bind 127.0.0.1 --directory dist
```

- `library-source.json`：九项经书与选读、译文、提示、阅读分组及版本信息。
- `source-manifest.json`：独立记录原文段数、顺序和 SHA-256，防止整理时漏段或混入其他文字。
- `glossary.json`：与正文关联的名词及深入导读链接。
- `config.js`：网站署名与名称。
- `build.py`：校验九项数据、359 段覆盖、原文哈希、62 组愿王偈及重要首尾，再生成 `book.js`。
- `build_site.py`：生成 `dist/`，按资源内容更新离线缓存版本。

修改后构建，并将更新的源文件、`book.js` 与 `sw.js` 一并提交。不要仅为绕过原文检查修改清单哈希；文字订正应先核对来源并记录理由。

## 发布

GitHub Pages → Deploy from a branch → `main` → `/(root)`。仓库根目录即含可发布资源，无需提交 `dist/` 或设置自定义工作流。所有资源使用相对路径。构建会给静态资源加上内容版本号，在线打开新版页面时直接获取对应资源，避免旧离线缓存覆盖新文案；离线仍可使用最近完整缓存的版本。

## 数据与授权

笔记只在浏览器中，未配置账号或自动云同步。请在清理浏览器、换设备前导出备份。本书架接受自己的备份及旧地藏站备份；《易经》备份独立。系统中文语音是否可用、是否离线可用，取决于浏览器和设备。

## 访问统计（Cloudflare Web Analytics）

已接入站主 Cloudflare 账号的 Web Analytics，使用官方客户端 beacon。网页不展示访问计数，也不提供公开统计面板；查看统计需要登录相应的 Cloudflare 账号。后台入口：[Cloudflare Web Analytics](https://dash.cloudflare.com/?to=/:account/web-analytics)，选择 `sunhow.github.io`，查看 `/fojing-reader/`。

- 只在正式主机 `sunhow.github.io` 的 `/fojing-reader/` 路径加载，本地预览不发送统计。
- 使用官方 `spa: false` 选项，统计文档打开／刷新，不把「看白话」、切换段落等操作增加为新的页面浏览。本站使用哈希路由，各经书与基础导读不会作为单独路径统计。
- 可查看页面浏览量、访问次数、来源、设备、国家地区等；访问次数不是精确的去重人数。
- 统计从接入后开始，历史访问不能补回。广告拦截、离线、网络失败等可能使数据漏计。
- Cloudflare 不提供个体访客追踪；本网站没有编写上传笔记、搜索词或阅读进度的统计事件。笔记的 localStorage 逻辑继续保持。
- HTML 中的站点 token 是公开的收集标识，不是账号 API 密钥，也不能用来读取后台报表。不要将账号密码或 API 密钥写入仓库。
- 参考：[官方接入说明](https://developers.cloudflare.com/web-analytics/get-started/)、[SPA 选项](https://developers.cloudflare.com/web-analytics/get-started/web-analytics-spa/)。

## 地藏经整合

书架显示顺序通过 `BOOK.readingOrder` 指定，原有八部经的数据索引、段落 ID 和链接不变。《地藏经》内部索引为 8（`#/ch/8`），沿用旧版 `pin-01` 至 `pin-13` 笔记键。首次自动合并以每条记录的时间戳判断；同时间保留本书架已有记录，空笔记删除标记也参与比较。原书架续读位置优先。只有保存成功才记录迁移标志；没有旧数据时稍后仍可迁移。
